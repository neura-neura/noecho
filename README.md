# NoEcho

Keep selected app audio private when you use remote desktop.

## Simple use

1. Run the NoEcho installer.
2. Select the apps that should stay private, such as Discord.
3. Press **Hide from remote**.
4. When finished, press **Restore normal audio**.

You keep hearing everything. The remote person hears the other apps normally.

The language can be changed in **Options** and is saved for the next time. English is the default; Spanish and Chinese are also available.

If NoEcho asks for a shared audio channel, press **Prepare shared channel** once. This is optional and each computer may have a different audio setup.

NoEcho does not change Cable A or Cable B. They can remain connected to MicVST and Mic Mix.

## Instalador de un solo clic
```powershell
npm run installer
```
The installer is generated in `dist-installer/`.

More installer details: `installer/README.md`.
